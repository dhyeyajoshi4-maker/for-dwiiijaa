# Dwiiijaaa website

This package contains NO MP4 files.

## Important
The website recreates the flower scene with HTML/CSS/JavaScript instead of loading a reference video.

## Add the song
Place your legally obtained audio file at:
`audio/made-in-japan.mp3`

The code will play it when the photo edit begins. The audio recording itself is not included.

## GitHub Pages
Upload `index.html`, `style.css`, `script.js`, and the `audio` folder to the root of a public GitHub repository. Then Settings → Pages → Deploy from a branch → main → /(root).

## Photos
The person opening the site selects the photos directly from their phone/browser. The selected photos are not uploaded to GitHub or a server; they are used locally in that browser session.
