# For you, Dwiiijaaa 🌷

This is a self-contained GitHub Pages website.

## How it works
1. The page opens with `for you, Dwiiijaaa` over the flower/gift animation reference supplied for this project.
2. After the flower sequence, the recipient chooses the photos on their phone.
3. The chosen photos are used automatically in the edit. Nothing is uploaded to a server.
4. Optionally, choose an audio file on the same device to play during the edit.
5. The flower sequence returns at the end.

## GitHub Pages
Upload `index.html`, `style.css`, `script.js`, and the `assets` folder to the root of a public GitHub repository, then enable Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

## Audio
The site does not contain a copyrighted recording. If you have an audio file you are allowed to use, the page lets you select it locally before starting the edit.
